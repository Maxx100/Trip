2.4. Оператором не осуществляется обработка биометрических персональных данных.

  • поведенческие;
  • для форм обратной связи;
  • сторонние и рекламные.

3. Цели сбора персональных данных

3.1. Обработка персональных данных ограничивается достижением конкретных, заранее определенных и законных целей. Не допускается обработка персональных данных, несовместимая с целями сбора персональных данных.

3.2. Обработке подлежат только персональные данные, которые отвечают целям их обработки.

3.3. Персональные данные обрабатываются Оператором в следующих целях:

  • 3.3.1. Подготовка, заключение и исполнение гражданско-правового договора.
  • 3.3.2. Продвижение товаров, работ, услуг на рынке.
  • 3.3.3. Соблюдение требований законодательства в сфере туризма.

По каждой из указанных целей Оператор определяет состав персональных данных, категории субъектов, операции с данными, сроки обработки (до достижения цели, но не более трех лет, если иное не требуется законом), способ обработки (смешанный), правовые основания и порядок уничтожения данных.

4. Правовые основания обработки персональных данных

4.1. Правовыми основаниями обработки персональных данных являются:

  • Конституция РФ;

  • ФЗ «Об основах туристской деятельности в РФ»;
  • Постановление Правительства РФ от 18.03.2023 № 417 (ЕИС «Электронная путевка»);
  • договоры, заключаемые между Оператором и субъектами персональных данных;
  • согласия субъектов персональных данных на обработку персональных данных;
  • иные основания, когда согласие на обработку персональных данных не требуется в силу закона.
